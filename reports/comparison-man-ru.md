## Обозначения:

- L — длина ключа
- n — количество ключей
- ℓ — размер диапазона запроса
- ε - вероятность ложного срабатывания

## 1. Overview

| Фильтр       | Базовый механизм                                                                                     | FPR зависит от распределения ключей?                 | Время запроса                                  |
|--------------|------------------------------------------------------------------------------------------------------|------------------------------------------------------|------------------------------------------------|
| **SuRF**     | Сжатый префиксный бор + опциональные суффиксные биты                                                 | Нет (опирается на независимость ключей и запросов)   | O(L)                                           |
| **SNARF**    | Двухуровневый Recursive Model Index, отображающий ключи в разреженный битовый массив с кодом Голомба | Нет (опирается на некоррелированные запросы)         | O(log n) на модель + O(k · β) на декодирование |
| **Rosetta**  | Иерархия из L фильтров Блума, индексируемая деревом отрезков                                         | Да (как у Блума; не зависит от распределения ключей) | O(log ℓ) ожидаемых обращений                   |
| **Grafite**  | Логически EXACTLY то к чему я пришел, но с другой hash function и другим сжатым вектором             | **Да**                                               | O(log(ℓ/ε))                                    |
| **Soda-Are** | Locality-Preserving hash + ERE (elias-fano encoding)                                                 | **Да**                                               | O(log(ℓ/ε))                                    |

FPR гарантия: **только Grafite и Rosetta имею гарантии на FPR на состязательных и коррелированных нагрузках.**
**SuRF** и **SNARF** могут быть приведены противником к FPR ≈ 1, если концы запросов около ключамей (умирают на
нагрузках) — нет гарантии в худшем случае.

## 2. Асимптотическая сложность

### Построение

| Фильтр    | Время      | Память (бит)                                |
|-----------|------------|---------------------------------------------|
| SuRF-Base | O(n · L)   | ≈ 10n (FST) + суффиксные биты (8 / 16 bits) |
| SNARF     | O(n log n) | (2 + log₂ℓ/ε)·n + 0.2·n ≈ (2.4 + log₂ℓ/ε)·n |
| Rosetta   | O(n · L)   | 1.44·n·log(ℓ/ε)                             |
| Grafite   | O(n log n) | n·log₂(ℓ/ε) + 2n + o(n)                     |
| Soda-Are  | O(n log n) | n·log₂(ℓ/ε) + 2n + o(n)                     |

Все имеют $O(n log n)$ или $O(n · L)$

![_mean.svg](../../bench_results/plots/b6_N16777216/build_throughput/_mean.svg)

### Запрос (длина диапазона ℓ)

| Фильтр    | Интервальный запрос                            | Комментарий                                                                                                                                                           |
|-----------|------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SuRF-Base | O(L)                                           | L байтовых сравнений вдоль пути в боре; раннего выхода нет                                                                                                            |
| SNARF     | O(log n) на модель + O(k · β) на декодирование | k = число затронутых блоков; β = 100 в этом репозитории. k ≈ 1 для равномерного распределения; неограниченно для состязательных нагрузок и при больших ошибках модели |
| Rosetta   | O(log L) ожидаемых обращений                   | Каждое обращение — это хеш Блума; ветвление doubting-дерева может взорваться: см. §5.2 ниже                                                                           |
| Grafite   | O(log(L/ε))                                    | Один поиск предшественника по Elias-Fano. Фиксируется на этапе построения через L, ε. **Не зависит от ℓ во время запроса.**                                           |

![_mean.svg](../../bench_results/plots/b6_N16777216/query_latency/_mean.svg)

### Оптимальность по помяти и FPR (нижняя граница: n·log(R/ε) бит, [Goswami et al., SODA 2014])

| Фильтр  | Константный множитель    | Зазор до границы                                                                            |
|---------|--------------------------|---------------------------------------------------------------------------------------------|
| Grafite | 1.0 + 2/log(ℓ/ε) → 1.0   | +2n + o(n) бит аддитивно                                                                    |
| Rosetta | 1.44×log(ℓ/ε)            | Константа Блума; совпадает с [Goswami] с точностью до ведущей константы                     |
| SNARF   | ≈ 2.4 + log₂ℓ/ε          | Добавляет 2.4 BPK сверху; не является приближением с константным множителем в худшем случае |
| SuRF    | Зависит от распределения | Нет аккуратной параметризации через ε; FPR не настраивается как параметр                    |

Grafite — единственный, кто укладывается в нижнюю границу с точностью до
аддитивных O(n) бит при любых (ℓ, ε). Rosetta оптимален с точностью до
константного множителя; SNARF и SuRF — нет.
